## Descripción del proyecto
NovaMarket CR es una plataforma de comercio electrónico que permite comprar y vender artículos para el hogar, decoración, organización y jardín.

## Problema que resuelve
Facilita la búsqueda y compra de productos para el hogar en un solo lugar y brinda oportunidades de venta a pequeños negocios.
